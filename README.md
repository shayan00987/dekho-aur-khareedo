# Dekho aur khareedo — responsive website concept

A responsive, static 6-page website concept for the public channel information shown in the supplied screenshots.

## Pages
- `index.html` — Home / landing page
- `about.html` — Creator profile
- `services.html` — Promotion services
- `work.html` — Channel showcase
- `welfare.html` — Stated welfare mission
- `contact.html` — Email, WhatsApp and enquiry form

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder from this ZIP.
3. In repository Settings → Pages, select deployment from the main branch and the root folder.
4. Save and wait for GitHub Pages to publish.

## Important notes
- Contact details and channel figures were transcribed from the screenshots provided. Confirm that they are current and that you have permission to publish this site on behalf of Rehan Ali before going live.
- The enquiry form uses `mailto:` and does not have a backend or store submissions.
- Product panels on the Work page are illustrative CSS artwork, not photographs of verified campaigns.
- The website is English-only in this first version. A language toggle and Urdu translation can be added in a later version.
- Google Fonts are loaded from Google Fonts when internet access is available; the layout remains usable if they fail to load.
